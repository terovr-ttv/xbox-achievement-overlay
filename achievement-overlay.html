Streamer.bot owns all triggering — chat phrases, subs, follows, redemptions, whatever. Whenever it decides an achievement unlocked, broadcast this shape over the WebSocket and the overlay just renders it:

CPH.WebsocketBroadcastJson(
  "{\"achievementName\":\"" + achievementName + "\"," +
  "\"unlockedBy\":\"" + user + "\"," +
  "\"points\":" + points + "," +
  "\"color\":\"" + color + "\"}"
);

achievementName, unlockedBy, and points populate the toast text. color sets its accent (hex, with or without the leading #) — omit it to use the preview color above.

This claude.ai preview is sandboxed and can't reach your local network — save the file and run it as an OBS Browser Source for live connections to work.
